# Graduate Applied Bioinformatics Research Innovations and Experiential Learning (GABRIEL)

*A Virtual Training and Mentoring Program*

---

## Introduction

The **Graduate Applied Bioinformatics Research Innovations and Experiential Learning (GABRIEL)** program is a **virtual training and mentoring initiative** led by **Toluwase Fatoki**.

GABRIEL is designed to **empower hundreds of new graduates** in the life sciences and related disciplines by equipping them with **applied bioinformatics research skills, computational methods, and experiential learning opportunities**.

The mission is to create a new generation of early-career scientists who are not only trained in theory but also **engaged in hands-on, project-based bioinformatics research**, ready to tackle pressing global health and biotechnology challenges.

---

## Requirements

Before starting the application process, ensure you have:

* **Computer** (Windows, macOS, or Linux).
* **Stable Internet Connection**.
* **Python 3.10+** installed.
* Required Python libraries installed:

```bash
pip install flask requests
```

---

## How to Run the Application

1. **Clone this Repository**

   ```bash
   git clone https://github.com/Heze-Sapience/gabriel-application.git
   cd gabriel-application
   ```

2. **Run the Application**

   ```bash
   python app.py
   ```

3. **Access the Form**

   * Open your browser and go to:

     ```
     http://127.0.0.1:5000
     ```

---

## Application Instructions for Applicants

1. **Fill Out All Required Fields**

   * Provide full name, email, WhatsApp number, and academic details.
   * Send required documents (CV, transcripts, etc., if requested).

2. **Submit the Form**

   * Click the **Submit** button when all required fields are completed.

3. **Receive Confirmation**

   * An **automatic confirmation email** will be sent to the email address provided.
   * If not received within 10 minutes, check **Spam/Junk** or contact the program team.

---

## What Happens After Submission?

* Your application will be logged automatically in the program’s secure database.
* All submissions will be reviewed.
* Selected mentees will be notified and receive program instructions.
* Attend 12 weeks of virtual training.
* Participate in cohort final research project.
  
---

## Potential Benefits

* Receive GABRIEL e-Book.
